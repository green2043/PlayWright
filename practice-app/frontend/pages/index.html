Welcome to the Playwright & Selenium Practice Ground

This application is intentionally packed with every kind of element, widget, popup, table, calendar, iframe and API pattern you need to practice UI and API automation with Playwright (TypeScript) and Selenium.

Hover over this paragraph to see a native tooltip (practice for getByTitle()).

📖 Sitemap

  • Forms — every form control type, validation states, labels/placeholders.
  • Tables — static, sortable, paginated, editable, and checkbox-selection tables.
  • Popups & Dialogs — native alert/confirm/prompt, custom modals, toasts, nested modals.
  • iFrames — single and nested iframes.
  • Dynamic Content — delayed elements, infinite scroll, lazy images, spinners, progress bars, calendars.
  • Shadow DOM — a custom web component using Shadow DOM.
  • Locator Playground — dedicated elements for every Playwright built-in locator strategy.
  • Files — file upload (single/multiple/drag-drop) and downloads (.txt/.csv/.json/.pdf).
  • Child Pages — parent/child page navigation practice (opens in a new tab).
  • API Playground — trigger and inspect REST API calls from the UI.
  • Advanced Elements — real-time SSE feed, clipboard, geolocation, notifications, live clock, drag-reorder, autocomplete, star rating.
