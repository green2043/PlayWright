    Job Title Dropdown (DOM-Injected, Focus-to-Close)

    An OrangeHRM-style div/span-based dropdown (like div.oxd-select-wrapper → div.oxd-select-dropdown → div.oxd-select-option) whose option list does NOT exist anywhere in the page's initial HTML. It is created and appended to the DOM ONLY at the moment you click the toggle, and is removed from the DOM again when an option is selected, when you click outside the dropdown, on Escape, or the moment the page/window loses focus (blur - e.g. right-clicking to open the browser context menu, or DevTools stealing focus via F12/Inspect). Because a normal right-click → "Inspect" triggers that blur event, the option list is removed from the DOM before DevTools can select it in the Elements panel. To inspect its real markup, first run the Chrome DevTools command menu (Ctrl+Shift+P) → "Emulate a focused page" BEFORE opening the dropdown - this suppresses the blur event so the page keeps believing it never lost focus, letting the option list survive long enough in the DOM to inspect normally.
